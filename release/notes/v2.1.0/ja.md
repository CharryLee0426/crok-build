Crok Desktop 2.1.0 は、このフォークのネイティブ macOS アプリです。エージェントのランタイムと `crok` ターミナル UI である crok を同梱しているので、ほかにインストールするものはありません。2.0.4 の次のリリースです。2.0.4 では、リモートのプロンプトに写真とファイルを添付できるようになりました。2.1.0 は、7 番目のモデルプロバイダーとして Meta Model API とその Muse モデルを、ターミナルと Crok Desktop に加えます。Web とスマートフォンアプリは、セッションのモデルと思考レベルを一緒に表示するようになり、リストから開いたセッションでもそれが適用されます。Crok Desktop はアクティブなウインドウでだけガラスを描き、入力欄のガラスは自前で描画します。そのため、ほかのアプリの後ろにあるアイドル状態のウインドウは通常のウインドウと同程度の負荷になり、ミッションコントロールも滑らかなままです。選択したフィードバックの親指のアイコンは塗りつぶされ、**他のコンピューター**のステータスドットは大きくなり、オンライン時は緑になります。

このリリースも 2.0.4 と同様に、プルリクエストがマージされるとすぐに GitHub Actions がビルドして公開します。

### インストール

1. お使いの macOS のバージョンに合うディスクイメージをダウンロードして開きます。どちらを選ぶかは、**どのディスクイメージをダウンロードするか** の表にあります。
2. **Crok Desktop** を **アプリケーション** にドラッグします。
3. アプリケーションから Crok Desktop を開きます。このビルドは公証されていないため、初回は macOS がアプリを検証できないと表示します。メッセージを閉じ、**システム設定 › プライバシーとセキュリティ** を開いて、Crok Desktop のメッセージの横にある **このまま開く** をクリックし、確認してください。この操作は一度だけです。
4. **設定 › アカウント** で、OpenRouter、OpenAI Codex、Anthropic API キー、DeepSeek API キー、Meta Model API キー、または GLM Coding Plan のキーでサインインします。

macOS 14 Sonoma 以降、Apple シリコン（M1 以降）が必要です。

### どのディスクイメージをダウンロードするか

どちらのイメージも Crok Desktop 2.1.0 で、機能は同じです。違いはビルドに使った macOS SDK だけで、これによってウインドウの外観に Apple の Liquid Glass が使われるかどうかが決まります。

| ディスクイメージ | ビルドに使った SDK | 使う macOS | タイトルバー |
| --- | --- | --- | --- |
| `Crok-Desktop-2.1.0-arm64-macOS26-SDK.dmg` | macOS {{SDK26}} SDK | macOS 26 以降 | Liquid Glass |
| `Crok-Desktop-2.1.0-arm64-macOS15-SDK.dmg` | macOS {{SDK15}} SDK | macOS 14 と 15 | ウインドウ内のすりガラス風のぼかし |

macOS 26 以降では、Liquid Glass のタイトルバーを使うために macOS 26 SDK のイメージを選んでください。macOS 14 または 15 では、macOS 15 SDK のイメージを使ってください。より新しい macOS でも動くので、どちらの macOS か分からない場合はこちらが安全です。入力欄はどちらのイメージでも同じように描画されます。

`crok-2.1.0-aarch64-apple-darwin.tar.gz` は `crok` ターミナル UI 単体で、アプリを入れたくない Mac 向けです。展開して `crok` を `PATH` の通った場所に置いてください。スマートフォンアプリについては、**スマートフォンアプリ** で説明しています。`SHA256SUMS.txt` はすべてのダウンロードファイルの SHA-256 の一覧、`SHA256SUMS.txt.sig` はその一覧の署名で、アップデート機能がこれを検証します。

### スマートフォンアプリ

iPhone と Android 用の Crok アプリは、各コンピューターのセッションを追い、その返答と権限のリクエストを表示し、どこからでもタスクを開始したり操作したりできます。このリリースのスマートフォンアプリは新しく、開いているセッションのモデルと思考レベルを一緒に表示し、古いコンピューターがプロバイダーの流儀で名付けたモデルでも一覧から見つけます。これを得るには、2.0.4 のアプリの上にインストールしてください。2.0.4 以前のスマートフォンアプリも従来どおり動作します。3 つのファイルはいずれも本番リレーにサインインします。

- **Android 8.0 以降**：スマートフォンで `Crok-Android-2.1.0.apk` をダウンロードして開きます。Android に求められたら、ブラウザにアプリのインストールを許可してください。または `adb install -r Crok-Android-2.1.0.apk` を実行します。この APK は 2.0.0 で導入されたリリース用の鍵で署名されているため、以前のリリースの APK の上にそのままインストールできます。自分でビルドした Crok の APK は別の鍵で署名されていて、インストールを妨げます。先に `adb uninstall dev.chenli.crok.mobile` を実行するか、スマートフォンの設定から削除してください。
- **iPhone と iPad、iOS 17 以降**：`Crok-iOS-2.1.0-unsigned.ipa` は署名されていません。iOS デバイス向けのアプリは、インストールする人の Apple ID で署名されるためです。AltStore や Sideloadly などのサイドロードツールでインストールしてください。これらのツールがお使いの Apple ID で署名します。無料の Apple ID の場合、7 日たつと、もう一度インストールするまで iOS はアプリを開かなくなります。代わりに自分でビルドする場合は、**Release** 構成を使ってください。Xcode の Run ボタンは Debug をビルドし、そちらはテスト用リレーにサインインします。
- **iOS シミュレータ**：`Crok-iOS-2.1.0-Simulator.zip` を展開すると `Crok.app` になります。Xcode のある Mac で `xcrun simctl install booted Crok.app` を実行するためのものです。

スマートフォンをサインインさせるには、**GitHub または Google で続ける** をタップし、開いた https://crok.chenli.dev のページでサインインして、**承認** をタップします。続いて、各コンピューターをリンクします。そのコンピューターで `crok remote login` を実行し、表示された QR コードをアプリの **設定 › コンピュータをリンク** から読み取るか、開いた Web ページでそのコンピューターを承認してください。

### 主な変更

- **Meta Model API、7 番目のプロバイダー。** ターミナルと Crok Desktop は、Meta 自身の Model API にサインインできます。料金は Meta アカウントにトークン単位で請求され、キーは dev.meta.ai で取得します。`crok login meta` はキーを表示せずに入力を求め、保存する前に Meta で検証します。拒否されたキーは保存されません。`meta-code` と `muse` は別名で、`META_API_KEY` と `MODEL_API_KEY` でも同じようにサインインでき、`crok logout meta` は保存されたキーを削除します。Crok Desktop の **設定 › アカウント** とターミナルの初回メニューに、このプロバイダーが並びます。
- **Muse モデル。** サインインするとアカウントのモデル一覧を取得し、その後は 1 時間ごとに更新します。組み込みの一覧は Muse Wonder、Muse Spark 1.3、1.2、1.1、それらの Contributor モード版、Muse Ember です。Meta が後から公開するモデルは `meta/<model>` という ID ですぐに使えます。これらのモデルはテキスト、画像、PDF、音声、動画を読み取ります。常に推論し、`/effort` では `minimal`、`low`、`medium`、`high`、`xhigh`、`max` を選べます。既定は Muse Wonder と Muse Ember が `max`、Muse Spark が `high` です。Meta が拒否するため `none` はなく、Contributor 版は `xhigh` までです。
- **セッションのモデルと思考レベルを常に一緒に。** Web、iOS、Android で開くとモデルの ID だけが表示され、思考レベルのピルが出ないことがありました。crok はセッションのモデルをモデル一覧の ID で名付けるようになったので、各デバイスはモデルとそのレベルを見つけられます。古い crok のセッションはプロバイダーの流儀でモデルを名付けますが、それでもプロバイダーを除いた ID、次に名前で見つけます。一覧の読み込み中は、思考レベルのピルがセッション自身のレベルを表示します。モデルの一覧にないレベルは、**デフォルト** ではなくそのレベルの名前で表示します。ピルが出ないのは、一覧がそのモデルにレベルがないと示している場合か、一覧もセッションもレベルを名付けていない場合だけです。
- **描画コストの低いガラス。** アクティブなウインドウのガラスだけが生きて動きます。システムのサイドバーと同じです。ほかのアプリの後ろにあるウインドウは単色で描画され、ウエルカムページのカードも流れなくなります。ミッションコントロールへのスワイプは、外付けディスプレイがあるときほど、もう引っかかりません。4K ディスプレイを接続した M1 で、Crok が Finder の後ろにあるときのミッションコントロールの GPU 使用率は平均 14.1 から 8.9 に（p90 は 46 から 31）なりました。
- **入力欄は Liquid Glass ではなく描画に。** ウインドウ内で何かが変わるたび、まばたきするカーソルでも、ウインドウサーバーは Liquid Glass を描き直します。入力欄の表面は、すりガラス風の素材と、影、塗り、光る縁、輝き、細い線を収めた 1 つの Canvas で描くようになり、255 段階のうち数段階の差でシステムの見た目に一致します。同じ M1 と 4K ディスプレイで、Crok を前面に置いたアイドル時の GPU 使用率は約 25 から 10.6 に、Crok を前面に置いたミッションコントロールは 18.8 から 13.0 になりました。
- **小さな改善。** 親指を選ぶとアイコンが塗りつぶされ、評価が一目で分かります。**他のコンピューター** のオンラインのドットは 10 ポイントで緑色の光輪を持ち、オフラインのドットも同じ大きさの灰色になりました。

### リモートコントロール

このリリースのすべての crok は、2.0.4 と同じく https://crok.chenli.dev の本番リレーにサインインし、すでにあるサインインをそのまま使います。本番リレーは、このリリースが公開されるときに Web 側の変更を取り込みます。コンピューター側の変更は、そこに crok 2.1.0 が入ってから効きます。

- **モデル名。** セッションはモデルをプロバイダーの流儀で保存します（`claude-sonnet-5-5`、`deepseek-flash`、OpenRouter の `deepseek/deepseek-v4.1-flash`）。一方、crok が公開する一覧はカタログキーで名付けます（`anthropic/claude-sonnet-5-5`、`deepseek/deepseek-flash`、`openrouter/deepseek/deepseek-v4.1-flash`）。crok 2.1.0 は一覧の ID を送るので、Web とスマートフォンはモデルとその思考レベルを見つけられます。コンピューターがもう提供しないモデルは、元の名前のままです。
- **古い crok。** crok 2.0.4 以前しか動いていないコンピューターは、モデルをプロバイダーの流儀で名付けます。Web とこのリリースのスマートフォンアプリは、プロバイダーを除いた ID で見つけるので、モデルとそのレベルは表示されます。ID がそのまま出るのは、どちらの形式にも一致しない場合だけです。
- **2 つのピル。** Web、iOS、Android はセッションのモデルと思考レベルを一緒に表示します。コンピューターの一覧がまだ届いていない間は、モデルを表示し、思考レベルのピルにはセッションのレベルを出します。古い crok で一覧がない場合は、両方のピルが暗くなり、タップするとそのコンピューターはまだモデルの選択肢を出せないと表示します。モデルの一覧にないレベルは、そのレベルの名前で表示されます。
- **コンピューターを更新してください。** Meta Model API と正確なモデル名には、各コンピューターの crok 2.1.0 が必要です。2 つのピルのために、上の **スマートフォンアプリ** の説明どおり、このリリースのスマートフォンアプリをインストールしてください。

### フィードバックと Agent Observability

報告は 2.0.4 と同じです。このリリースのすべての crok は、行った各モデル呼び出しを、ターン、ツール実行、ステップ、ガードチェックとともに、メンテナーの Grafana Cloud スタック上の [Grafana Agent Observability](https://grafana.com/docs/grafana-cloud/machine-learning/agent-observability/) に報告します。`crok version --json` は報告先のホストを `agentObservability` に表示します。Crok Desktop またはターミナルの親指は、そのターンの会話に記録され、`crok_feedback_rating` ゲージにもなります。取り消すと中立として記録されます。

報告をやめるには、`~/.crok/config.toml` の `[features]` に `agent_observability = false` を追加するか、`CROK_AGENT_OBSERVABILITY=0` を設定します。自分のスタックに報告するには、リポジトリの `crates/codegen/xai-grok-agento11y/setup.sh` で `~/.crok/agento11y.env` を書きます。

### 開発者向け

- Meta は独自の Chat Completions 方言を持つ `ApiBackend`（`meta`）です。`GET /v1/models` はサインイン時と 1 時間ごとに取得し、`~/.crok/meta-models.json` にキャッシュします。最初の取得までは組み込みの一覧を使います。`provider_compat.rs` は `none` と `minimal` を `minimal` として送り、推論が同じ出力予算を使うため 4,096 未満の `max_tokens` を引き上げ、強制ツール呼び出しを言葉で求めつつ `tool_choice: "auto"` を送り、ネイティブの JSON schema をそのまま残し、再生するターンから `reasoning_content` を、また `frequency_penalty` と `presence_penalty` を削除します。
- モデルファミリー間の切り替えでは、Anthropic と同様に先に圧縮します。標準の費用は Meta の公開価格から見積もり、Muse Ember の 20 万入力トークンの長いコンテキストの段階と Contributor の料金を含めます。
- リモート：`bridge:upsertSession`（モデルが変わったときだけ）、`bridge:catalogBatch`、`catalogUpdate` は、`selectable_catalog_key_for_persisted` が解決するカタログキーでセッションのモデルを名付けます。これは再開したセッションのモデルを解決するのと同じ方法です。一覧にないモデルは名前を保ちます。契約は `relay/DESIGN.md` と `mobile/DESIGN.md` にあります。
- Web、iOS、Android は、セッションのモデルを ID、プロバイダーを除いた ID、名前の順に探し、セッションがレベルを名付けるときは常に思考レベルのピルを出します。Web のプレビューには新しいケース（`session-provider-model`、`session-models-loading`、`session-unknown-model`）があります。
- デスクトップ：`GlassBackdrop` はウインドウが非アクティブのとき単色を使い、別の領域の背景の上に色を重ねて、デスクトップを再度ぼかしません。`GlassSurface` は `FrostedGlass` の見た目を 1 つの Canvas で描きます。テストは、Liquid Glass のレイヤーが残らないことと、非アクティブなウインドウが単色で描かれることを確認します。
- リリースは従来どおり `.github/workflows/release.yml` が行います。`VERSION` を上げるプルリクエストが `main` にマージされると、すべてのファイルをビルド、検査、署名し、評価ゲートを実行して、`release/notes/v2.1.0/` のノートとともに公開します。

### 署名

2.1.0 は、2.0.4、2.0.3、2.0.2、2.0.1、2.0.0、1.5.2、1.5.3 と同じ "Crok Code Signing" 証明書で署名されています。macOS はプライバシー権限を署名に結び付けているため、2.0.4 に許可したもの（「画面収録」、「アクセシビリティ」、マイク、音声認識）は 2.1.0 に引き継がれます。このビルドは公証されていないので、新しくインストールする場合は上記の **このまま開く** の手順が一度必要です。

Android アプリは、2.0.0 で導入されたリリース用の鍵で署名されています。iOS アプリは、**スマートフォンアプリ** で説明しているとおり署名されていません。署名付きのチェックサム一覧は、これとは別のものです。アップデート機能がダウンロードしたファイルを検証するためのもので、macOS によるアプリの扱いは変わりません。

### 2.0.4 からのアップグレード

**Crok Desktop › アップデートを確認…** を使うか、Crok Desktop を終了してからターミナルで `crok upgrade` を実行します。今回のアップデートは、インストール済みの `Crok Desktop.app` にそのまま行われます。そのため Dock や Finder での位置はそのままで、古いコピーがゴミ箱に残ることもありません。アップデートは、インストール済みのアプリと同じ SDK でビルドされたイメージ（macOS26-SDK または macOS15-SDK）を取得し、もう一方になることはありません。

モデルプロバイダーへのサインイン、設定、タスク、リレーはいずれも引き継がれます。2.1.0 は 2.0.4 と同じ本番リレーと通信します。Meta Model API と正確なモデル名のために、リレーで使うコンピューターはすべて crok 2.1.0 に更新し、上の **スマートフォンアプリ** で説明しているとおり、このリリースのスマートフォンアプリをインストールしてください。

### 詳細

- GitHub Actions が、`main` のタグ `desktop-v2.1.0`（`{{COMMIT}}`）からビルドしました。macOS 26 SDK のイメージは Xcode {{XCODE26}} と macOS {{SDK26}} SDK、macOS 15 SDK のイメージは Xcode {{XCODE15}} と macOS {{SDK15}} SDK、単体の `crok` は macOS {{TUI_SDK}} SDK でビルドしています。
